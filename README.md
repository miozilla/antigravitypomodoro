# antigravitypomodoro 🌍🧑‍🚀
antigravitypomodoro : | Pomodoro Project |  Google Antigravity, AI agents Orchestration, Slash Command, Agent Skills, Model Context Protocol (MCP) Servers Integration |


## Objectives
- Configure & authenticate Google Antigravity application.
- Manage projects, conversations & security settings in Antigravity interface.
- Automate workflows using slash commands, schedules & Model Context Protocol (MCP) servers.
- Extend agent capabilities using artifacts, local code execution & custom skills.
- Perform various development operation :
  - Executing system commands
  - Performing file read & write operations
  - Conducting web searches
  - Integrating with external tools using skills & Model Context Protocol (MCP) servers
  - Managing concurrent subagents
  - Interacting with Chrome browsers
  - Generating plans & visual artifacts
